#### 01. Smart Disaster Mitigation Web Platform
**Bidang:** System Analysis & System Design  
Perancangan sistem website untuk penyediaan informasi kebencanaan dan pemantauan status kondisi sungai berbasis data sensor IoT di Desa Sriharjo, Bantul.
* Menyusun alur kerja sistem (*system workflow*) mulai dari autentikasi admin, pemantauan status wilayah, pengelolaan konten, hingga alur penerimaan data dari sensor IoT.
* Mendokumentasikan interaksi antarkomponen sistem menggunakan *Class Diagram*, *Sequence Diagram*, serta perancangan relasi antara *Database Informasi* dan *Database IoT*.
* Memetakan keterkaitan fungsi website, pengelolaan informasi berbasis lokasi (`locationID`), serta aturan penentuan status wilayah (*Aman, Waspada, Bahaya*).

**Dokumentasi Proyek:** [Smart Disaster Mitigation Web Portfolio](./Project_3_Smart%20Disaster%20Mitigation/MarhamaHasana_Smart%20Disaster%20Mitigation%20Web_Portofolio.pdf)

**Bidang:** System Analysis | Case Study

#### 04. Analisis Sentimen TikTok – Penelitian Skripsi
**Bidang:** Data Analysis & Research  
Penelitian tugas akhir yang mengkaji pengaruh *Social Media Engagement* dan sentimen publik terhadap minat beli produk MOP Beauty di TikTok menggunakan pendekatan teori *Stimulus–Organism–Response* (S-O-R).
* Melakukan analisis sentimen terhadap komentar audiens pada konten TikTok menggunakan metode *VADER Sentiment Reasoner*.
* Menganalisis indikator *social media engagement* yang meliputi jumlah *likes*, *comments*, dan *shares*.
* Menguji hubungan antarvariabel penelitian terhadap minat beli konsumen menggunakan metode *Partial Least Squares Structural Equation Modeling* (PLS-SEM) di SmartPLS.

**Judul Penelitian:** *Analisis Pengaruh Social Media Engagement dan Sentimen Publik terhadap Minat Beli Produk MOP Beauty di TikTok Berdasarkan Pendekatan Teori S-O-R.*

**Dokumentasi Proyek:** [Analisis Sentimen TikTok](./Project_4_Tiktok_Sentiment/MarhamaHasana_Data%20Analyst%20Tiktok%20MOP_Portofolio.pdf)
